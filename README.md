# Weather-App
A responsive Weather App built using HTML, CSS, and JavaScript. It uses the Open-Meteo API to fetch real-time weather information, including temperature, humidity, wind speed, and weather conditions.


# 🌦️ Weather App

A beautiful and responsive Weather App built using HTML, CSS, and JavaScript.

Search for any city and get its current weather information instantly.

## 🚀 Features

* Search weather by city name.
* Display current temperature.
* Show weather conditions with dynamic icons.
* Display humidity and wind speed.
* Recent city search history.
* Refresh weather information.
* Search using the Enter key.
* Responsive design for mobile and desktop.
* Error handling for invalid city names.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Open-Meteo API
* Font Awesome Icons

## 🌐 API Used

* Geocoding API: Open-Meteo
* Weather Forecast API: Open-Meteo
